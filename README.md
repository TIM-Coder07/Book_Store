# 📚 Online Book Shop

An interactive and modern **Online Book Store Web Application** built with React. Users can browse books, add to cart, manage wishlist, reading list, and complete purchase actions with a smooth UI experience.

---

## 🚀 Live Demo
https://your-live-site-link.com

---

## 🛠️ Tech Stack

- ⚛️ React 19
- 🌐 React Router v7
- 🎨 Tailwind CSS v4
- ⚡ Vite
- 📦 React Tabs

---

## ✨ Features

### 📖 Book Management
- Browse all available books  
- View detailed book information  

### 🛒 Cart System
- Add books to cart  
- Increase / decrease quantity  
- Remove items from cart  

### ❤️ Wishlist
- Save favorite books  
- Move wishlist items to cart  

### 📚 Reading List
- Add books to reading list  
- Track books you want to read  

### 💳 Purchase Flow
- Simple checkout system  
- Order summary before purchase
